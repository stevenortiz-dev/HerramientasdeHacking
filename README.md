# NetAudit · Herramientas de Análisis y Hacking de Redes 🛡️⚡

## 🚀 Características Principales

- **Simulaciones Operativas**:
  - 🔍 **Nmap**: Descubrimiento de superficie, escaneo de puertos (TCP SYN, UDP), detección de versiones (`-sV`) y scripts NSE (`--script vuln`).
  - 📡 **Wireshark**: Inspección profunda de paquetes, análisis de protocolos (TCP, DNS, HTTP, ARP) y seguimiento de flujos de red.
  - ⚡ **Bettercap**: Pruebas de seguridad en Capa 2 (ARP Spoofing, DNS Spoofing, sniffing de credenciales y auditoría de red local).
- **Video Demostración Integrado**: Demostración práctica de escaneo y auditoría en entorno Kali Linux.
- **Terminal Interactiva y HUD de Ciberseguridad**: Simulación visual en tiempo real de comandos y respuestas de auditoría.
- **Efectos Visuales Avanzados**: Fondo Matrix / lluvia de código en HTML5 Canvas con rendimiento optimizado.
- **Diseño Inmersivo de Pantalla Completa**: Scroll suave por diapositivas (`scroll-snap`), navegación limpia y modo oscuro de alto contraste.

## 💻 Cómo Ejecutar el Proyecto Localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/stevenortiz-dev/HerramientasdeHacking.git
   ```
2. Abre la carpeta del proyecto:
   ```bash
   cd HerramientasdeHacking
   ```
3. Abre `index.html` directamente en tu navegador o mediante una extensión de servidor local como **Live Server** en VS Code.
